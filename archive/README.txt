LIMITATIONS
This is not a full working clone of Triff.Tools. The original server-side fitting
engine, authentication, private fits, live markets, intel, reports, and several
calculators are unavailable. Read What's preserved in the app for exact coverage.
No complete site-specific kill order or best-fit ranking was invented. Trigger
markers and original fitting caveats are preserved. Wiki summaries are distinct
from Triff content. Original data may be outdated or contain errors.

Real EVE SSO is NOT configured. It requires a registered CCP application and an
approved redirect/authentication deployment. This ZIP never asks for passwords,
API secrets, or tokens. Public character lookup is the only online integration.

Prices and calculation snapshots are historical examples, not current earnings.
The redesigned interface uses no external scripts, fonts or analytics. The core
archive reads bundled data directly. External source links and public ESI lookup
need internet. The original folder contains source assets for provenance only;
its original page entry is not a tested offline version of Triff's application.
